# Java_Basic_Program

## Overview

This repository contains a collection of Java programs ranging from basic algorithms to data structure implementations and practice problems. The code is organized into different packages for clarity and ease of navigation.

## Structure

- **src/main/java/com/praveen/basic/**  
  Basic Java programs and algorithms (e.g., Fibonacci series).

- **src/main/java/com/praveen/array/**  
  Array-related programs and exercises.

- **src/main/java/com/praveen/array/PracticePrograms/**  
  Practice problems on arrays.

- **src/main/java/com/praveen/array/PracticePrograms/collections/**  
  Programs demonstrating Java collections (ArrayList, LinkedList, etc.).

- **src/main/java/com/praveen/array/PracticePrograms/collections/dsaProblems/**  
  Data structure and algorithm problems (matrix manipulation, string decoding, brackets validation, etc.).

- **src/main/java/com/praveen/dsa/**  
  Data structures and algorithms, including pattern problems.

## Getting Started

Browse the source code under `src/main/java/com/praveen/` for examples and solutions. Each package is self-contained and includes a `main()` method for demonstration.
